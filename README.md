# Stockpilot

Full-stack inventory management application.

## Features

- User authentication with JWT
- Product management
- Brand management
- Category management
- Product creation
- Product editing
- Product SKU
- Product quantity tracking
- PostgreSQL database

## Tech Stack

Frontend:
- React
- Vite

Backend:
- Node.js
- Express
- PostgreSQL
- JWT
- bcrypt

## Project Structure

client/  - React frontend
server/  - Express API
